# /pact-change — 需求变更入口（S10-CR，只改物料不写业务代码）

> 创建日期: 2026-08-02

**用户中途改需求时，绕过规格直接改代码 = PACT 立刻退化成过时的摆设文档。**
本命令把变更走完整的 S10-CR，改完**停在物料层**：施工交给 `/pact-run`，除非用户明确要求继续。

```bash
CORE="$(ls -d ./.claude/skills/pact ~/.claude/skills/pact 2>/dev/null | head -1)"
```

若 `$ARGUMENTS` 含 `--help`：只输出 `bash $CORE/scripts/pact-help.sh` 的内容然后停止。

## 第一步：定位物料 + 前置分流

1. 定位规则与 `/pact-run` 相同：给了路径用路径；没给则扫描 `.pact/*/PACT.md`——
   恰一份直用并说明；0 份指去 `/pact-new`；≥2 份 `AskUserQuestion` 让用户选
   （变更描述通常能提示属于哪份物料，把最可能的设为推荐项）。
2. **未冻结的物料不走 CR**：直接在草稿上改（按 `board.md` 回到对应工序，用 `/pact-new` 的规则续写），
   本命令到此为止并说明原因。
3. 读清变更描述。描述含多个独立变更 → 拆成多条，逐条走流程、逐条编号。

## 第二步：变更分类（决定走哪些动作）

| 类型 | 判定 | 额外动作 |
|---|---|---|
| 新增需求 | 规格里没有的能力 | 新 R-ID（全项目最大号 +1，不复用已删号） |
| 修改需求 | 已有 R-ID 语义/验收变化 | 改原条目；已实现的 step 状态回退为 `todo` 并注明原因 |
| 删除需求 | 不再要了 | R-ID 标 `已删除（日期+原因）` 不删行；相关 step 删除或标注 |
| 推翻决策 | 与 `A5` 某条 D-ID 冲突 | 新增 D-ID 说明为什么推翻，旧条标 `已被 D0xx 取代`，**不要删** |

变更与 `P6` 非目标或 `P7` 硬约束冲突 → **停下 `AskUserQuestion`**，不得自行放宽约束。

## 第三步：S10-CR 六步（一步不能省）

1. **回 `P5`** 加/改 R-ID（同时更新受影响的 `P6`/`P4`）；
2. **回 `T1`** 给每个新/改 R-ID 补可执行验收——**没有验收方式就不算需求**；
3. **影响契约** → 同步改 `C` 层对应锚点（表结构/接口/错误码/配置/权限）；
4. **记 `changelog.md`**：日期 / 改了哪些锚点 / 改成什么 / **为什么** / 影响哪些 R-ID；
5. **门禁判定**：改到 `P1/P2/P4/P5/P6`（意图与范围层）→ **重跑 S8 冷读门**
   （`Agent` 工具 + `$CORE/templates/cold-read.md`，报告追加 `cold-read.md`）；
   只改 C 层细节不动语义 → 跑 `pact-lint.sh` 即可；
6. **同步执行图谱 + 知识库**：
   - 新/改 R-ID 在 `action-graph.json` 加 feature/step 承接、连 deps（变更超出当前里程碑 →
     排 `T5` 后续里程碑，**不塞进正在做的单元**）；
   - `bash $CORE/scripts/pact-graph.sh <物料目录>` 结构 PASS；
   - `bash $CORE/scripts/pact-book.sh <物料目录>` 重生成知识库
     （改到流程图/结构图块 → 构建会报图过期，按 `$CORE/references/svg-figure-guide.md` 重绘对应 `figures/*.svg`）；
   - `bash $CORE/scripts/pact-lint.sh <物料目录>/PACT.md` 复检。

## 第四步：影响面报告（最终消息必须包含）

- **变更清单**：每条变更 → 类型 → 落到哪些 R-ID / 锚点 / D-ID；
- **图谱影响**：新增/回退/删除了哪些 step，完成度从 N% 变为 M%（`pact-graph.sh` 输出）；
- **门禁结果**：lint / graph / 冷读门（若触发）各自 PASS/FAIL；
- **工期影响**：变更影响估算前提或新增 T3 级条目时，提示用 `/pact-estimate` 重估——
  **不要顺口给"多不了几天"这类数字**（禁令 11）；
- **下一步**：`/pact-run <物料目录>` 施工。

**禁令**：本命令不写业务代码、不改既有实现；变更没走完六步之前不得宣称"变更完成"。
